# Семантическое ядро EasyDays Samui

> **Дата**: 16.04.2026  
> **Сайт**: easydayssamui.com  
> **Основная аудитория**: русскоязычные семьи (Google, Yandex), англоязычные экспаты (Google)  
> **Оценки частотности**: Yandex Wordstat для RU запросов, Google Keyword Planner для EN. Нишевые запросы с гео Самуи имеют малые абсолютные объемы (50-500/мес), но высокую конверсию.

**Условные обозначения:**
- Частотность: ВЧ >500/мес, СЧ 100-500/мес, НЧ <100/мес (для нишевых гео-запросов шкала сдвинута вниз)
- На сайте: + есть, - отсутствует, ~ частично (упоминается, но не оптимизировано)
- Интент: I информационный, T транзакционный, N навигационный, C коммерческий
